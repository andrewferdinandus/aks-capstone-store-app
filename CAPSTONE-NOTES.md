# AKS Capstone Store App

This application repo is based on/adapted from the Microsoft Azure sample project:

Azure-Samples/aks-store-demo

The app is used as the sample microservices workload for the Enterprise AKS DevOps / DevSecOps / Platform Engineering Capstone.

In this capstone, the application will be connected with:

- Azure Container Registry
- GitHub Actions CI
- SonarCloud quality checks
- Trivy container scanning
- Argo CD GitOps deployment
- Gateway API routing
- Prometheus/Grafana monitoring
- OpenTelemetry observability
- AIOps incident analysis and PR remediation
